# Calc

Калькулятор для Android: открывается во весь экран, сворачивается в плавающее окно поверх других приложений с регулируемой прозрачностью.

**Скачать:** [calc.apk](https://github.com/krasn0w/calc/releases/latest/download/calc.apk) — собирается автоматически при каждом пуше в `main`.

- Вверху: свернуть в окно / развернуть во весь экран и закрыть.
- Окно: перетаскивание за любое свободное место, размер — за уголок справа внизу, прозрачность — ползунком.
- `⌫` стирает символ, долгое нажатие — всё. После `=` кнопка становится `C`.
- Повторное `=` повторяет последнее действие: `2 + 3 = = =` → 5, 8, 11.
- `⋯` открывает панель: память `MS` `MR` `M+` `M−` (долгое нажатие `MR` — очистить память), скобки, `xʸ`, `√`.
- Проценты как на обычном калькуляторе: `200 + 10%` = 220, `−30 + 50%` = −45.
